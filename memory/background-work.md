# claude-plus-fa: background work and the card popover

What is true now; history in [`trials.md`](../trials.md). Limits of these features stay in `memory.md` § Limits.

## Background work badge
- An open session's card shows a turning arc and a count on its title row (`--surface2` on `--muted`, 16 px, before the age; in the tab on top); gone when nothing runs; arrow 1.6 s a turn (still under reduced motion). Closed sessions have none. It has no tooltip: its pieces are listed in the card's popover. The card's `aria-label` ends with `bgSaid()` (*2 background runs, 3:10*).
- It counts child runs and subagents only; background commands are not counted (they would need a transcript read on every live pass), they appear only in the popover.
- The session's own look (`stateOf()`) is unchanged by background work: dot and tint show only the session's own state; the hero conducts (memory.md, Mascot). The time's place shows how long the work has run (`bgSince`, `Panel.bg_start()`) unless the session is itself working.
- Computed in `Panel.background()` on every live pass and scan from the Toolhelp snapshot `procs()`; it also keeps the session files of that pass in `Panel.live` for `peek()`.
- Child runs (`child_runs()`): processes that are Claude Code by full path (`~/.local/bin/claude.exe`, `claude.exe.old.*`, files under `~/.local/share/claude/versions/`; `QueryFullProcessImageNameW`) whose parent chain reaches an open session's pid, the nearest winning; each parent no younger than its child (`born()`); a process holding the same session id is not a run; a Claude Code process straight under another without a session of its own (`claude mcp serve`) is skipped. Folder from its session file; start from its own `claude.exe` creation time (`GetProcessTimes`). Each item also carries `pid`, its own session id `sid` and `cwd`.
- Subagents (`subagents()`): `<transcript folder>/<session id>/subagents[/<subfolder>]/agent-<id>.meta.json` without `finished` or `stoppedByUser`, written since the session's process started; walked with `os.scandir`, a meta re-read only when its mtime changes (`Panel.metas`); start from the agent's `.jsonl` creation time; the item carries that `.jsonl` as `file`.
- Work without a start of its own takes the first read that saw it (`Panel.bg_seen`, forgotten once nothing runs).

## Card popover
- Hovering any card (right dock, top tab, set-aside cards) opens a popover 400 ms after a real mouse movement over it; it stays while the pointer is on the card and closes when it leaves. Any pointer press, right-click, wheel, key, focus change, window blur, list scroll, resize, drag or dock change closes it; after a press or key it reopens only once the pointer has left that card. No auto-close after 3 s (unlike the tooltips).
- It is the card's only hint: the card's dot, title, time, ctx and badge have no tooltips of their own. Content: full title (12 px, 600), folder (`where_of()`), state line (`said()` plus flags, ticking each second); *Last Prompt* clamped to 4 lines; when background work runs, *In the Background · <time since the oldest>* then one row per piece: kind (*Subagent*, *claude -p*, *Command*) · description · time run (ticking), and its prompt or command clamped to 2 lines; oldest first. No count in the heading, since the badge does not count commands.
- Look: the tooltip's class `.tip` plus `.peek` (navy at 88 %, 11 px, white), 264 px wide on the right, 340 px on top; `pointer-events: none`, `aria-hidden`, no focus, keys never prevented. Never scrolls: rows that do not fit are dropped from the end and counted (*and n more*), at most `PEEK_ROWS` 8.
- Place: right dock above the card when it fits, else below, else on the side with more room; top dock under the tab. On top it is part of the window region (`syncRegion` reports every `.tip`).
- Data: the page calls `api().peek(id)` when it opens and again on every `app.update()` while open; `Panel.peek(sid)` returns `{id, prompt, bg: [{kind, what, text, since ms}]}`, or `None` for an unknown session; a closed session gets its prompt only. Nothing is kept by the page, written or logged.
- Readers (only for the hovered card; caches in `Panel.peeks` by transcript path):
  - `last_prompt()`: the last line of the transcript that `typed_prompt()` accepts (a `user` line that is not meta, sidechain, a tool result, a tag such as `<task-notification>` or `<command-name>`, a compaction summary or an interruption), searched in the last `PEEK_TAIL` 256 KB, then `PEEK_MORE` 4 MB; cached by (size, mtime).
  - `first_prompt()`: the first user line of a subagent's `.jsonl` or of a `claude -p` run's own transcript (`projects/<slug(cwd)>/<sid>.jsonl`), read from the first `PEEK_HEAD` 256 KB, cached for good once found. A run without a transcript (`--no-session-persistence`) falls back to its command line (`command_line()`: `NtQueryInformationProcess` class 60 + `CommandLineToArgvW`; `print_prompt()`: the argument after `-p`/`--print`, else the longest non-option); a prompt given on stdin shows none.
  - `bg_commands()`: in the last `BG_TAIL` 4 MB, a `tool_use` with `run_in_background` (not Agent/Task) whose `tool_result` says `running in background with ID: X` at or after the process start, without a later `<task-id>X</task-id>` or a `TaskStop`/`KillShell` of X; cached by (size, mtime, start). Shown only when `late_child()` finds a child of the session's process born over `LATE` 20 s after it started. Same rule as `busy_work()` in `glm-fallback.py`.
  - `flat()`: whitespace collapsed, BOM removed, cut at `PEEK_CHARS` 1200 with `…`.
- Cost measured on a real 4 MB-tail session: first `peek()` 48 ms, cached 0.9 ms.
